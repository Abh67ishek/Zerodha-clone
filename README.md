# 📈 Zerodha Clone – Full Stack Trading Platform

A full-stack stock trading platform inspired by Zerodha, built using the MERN stack.
This project simulates real-world trading workflows including user authentication, portfolio tracking, and order management with a clean and responsive UI.

---

https://zerodhas-clone-seven.vercel.app/
https://zerodha-dashboard-eight-beryl.vercel.app/

## 🚀 Features

* 🔐 User Authentication (Login / Signup with secure handling)
* 📊 Interactive Trading Dashboard
* 💼 Portfolio Management (Holdings & Positions)
* 📈 Stock Listing & Price Simulation
* 🛒 Buy/Sell Order Placement
* 🧑‍💼 Admin Panel (manage users / data)
* 📱 Responsive UI for all devices

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/zerodha-clone.git
cd zerodha-clone
```

---

### 2. Setup Backend

```
cd backend
npm install
```

Create a `.env` file inside `backend/`:

```
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```

Run backend:

```
npm start
```

---

### 3. Setup Frontend

```
cd frontend
npm install
npm start
```

---

### 4. Setup Admin Panel (if applicable)

```
cd admin
npm install
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file in the backend folder.

Example:

```
PORT=5000
MONGO_URI=your_mongo_db_url
JWT_SECRET=your_secret
```

⚠️ Note: `.env` is not uploaded for security reasons.
